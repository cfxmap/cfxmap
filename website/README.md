# Website Directory

[中文](#website-directory-中文)

This directory contains the HTML files for the project's website/frontend display.

## Files
- `conflux.html`: A comprehensive guide to the Conflux ecosystem services. It includes:
    - **Funding Services**: Guides on USDT deposits/withdrawals, cross-chain transfers, and exchanges.
    - **Ecosystem Tools**: Navigation to blockchain explorers, cross-chain bridges, and stablecoins.
    - **Yield & Finance**: Tutorials and entry points for PoS staking, lending, and liquidity mining.
    - **Resources**: Information about wallets and other educational materials for the Conflux eSpace.

## Features
- **Responsive Design**: Adapts to different screen sizes.
- **Interactive Navigation**: Left-side navigation bar for easy access to different sections.
- **Multi-language Support**: Structure in place for language switching (currently set to zh-CN).

# Website Directory (中文)

此目录包含项目网站/前端展示的 HTML 文件。

## 文件说明
- `conflux.html`: Conflux 生态服务指南。内容包括：
    - **资金服务**：USDT 充提、跨链和兑换指南。
    - **生态工具**：区块链浏览器、跨链桥和稳定币导航。
    - **理财收益**：PoS 质押、借贷和流动性挖矿的教程与入口。
    - **资源**：关于钱包和 Conflux eSpace 其他教育资料的信息。

## 功能特点
- **响应式设计**：适配不同屏幕尺寸。
- **交互式导航**：左侧导航栏方便访问不同部分。
- **多语言支持**：已具备语言切换的结构（目前设置为 zh-CN）。
